# SkpShare: نمایش و اشتراک فایل‌های SketchUp

وب‌اپ + پلاگین SketchUp برای اینکه مدل‌ها را **مستقیم از اسکچ‌آپ** منتشر کنید، روی **موبایل، تبلت و لپ‌تاپ** سریع و بدون لگ ببینید، با لینک به اشتراک بگذارید، و فایل اصلی `.skp` را برای SketchUp Pro دانلود کنید.

> English summary at the bottom.

---

## چطور حجم ۶۰۰ مگ می‌شود ۲۰ تا ۵۰ مگ؟

پلاگین، روی کامپیوتر خود شما، دو فایل جدا می‌سازد:

| فایل | کاربرد | روش کم کردن حجم |
|---|---|---|
| **نسخه‌ی نمایشی (GLB)** | دیدن سه‌بعدی در مرورگر | هر کامپوننت فقط **یک بار** ذخیره می‌شود و تکرارهایش با GPU instancing کشیده می‌شوند. هندسه با meshopt فشرده و کوانتیزه می‌شود و بافت‌ها به KTX2 (Basis) تبدیل و حداکثر ۱۰۲۴، ۲۰۴۸ یا ۴۰۹۶ پیکسل می‌شوند. یک فایل **پیش‌نمایش** کوچک (ساده‌شده) هم ساخته می‌شود که در چند ثانیه باز می‌شود. |
| **فایل اصلی `.skp`** | دانلود و باز کردن در SketchUp Pro | با gzip فشرده ذخیره می‌شود و موقع دانلود دوباره به `.skp` عادی تبدیل می‌شود. |

نسخه‌ی نمایشی معمولاً ۱۰ تا ۳۰ برابر کوچک‌تر از فایل اصلی است. خود فایل `.skp` را نمی‌شود بدون تغییر محتوایش به این اندازه رساند، چون gzip روی آن فقط حدود ۱۰ تا ۴۰ درصد صرفه‌جویی می‌کند. به همین دلیل دو فایل جدا نگه داشته می‌شود.

## امکانات

- **پلاگین SketchUp (2021 به بعد)**: از منوی Extensions → SkpShare → Publish. انتخاب پروژه و مدل، نسخه‌ی جدید با یادداشت، سه کیفیت Light / Balanced / High، نوار پیشرفت. آپلود تکه‌تکه و قابل‌ادامه است، پس اگر اینترنت قطع شود از همان‌جا ادامه می‌دهد.
- **نمایشگر سه‌بعدی**:
  - Sceneهای اسکچ‌آپ با تصویر کوچک، و Tagها که می‌شود روشن یا خاموششان کرد.
  - نمای Top، Front و Iso، و حالت پرسپکتیو یا موازی.
  - حالت‌های نمایش X-Ray، Wireframe و تک‌رنگ؛ نمایش لبه‌ها؛ سایه و جهت خورشید.
- **سکشن**:
  - صفحه‌ی برش افقی (پلان) یا عمودی با اسلایدر و دستگیره‌ی کشیدنی.
  - برش روی هر سطحی که لمس کنید.
  - **Section Box** شش‌وجهی.
  - استفاده از Section Planeهای خود اسکچ‌آپ.
  - **پر کردن رنگی برش‌ها** (رنگش قابل تغییر است).
- **ابزارها**:
  - اندازه‌گیری فاصله، ارتفاع، زاویه و مساحت با چسبیدن به گوشه‌ها، وسط لبه‌ها و لبه‌ها.
  - خط کشیدن روی مدل و ماژیک هایلایت.
  - پین کامنت سه‌بعدی با پاسخ و حالت باز یا حل‌شده.
  - مارکاپ دوبعدی روی اسکرین‌شات (قلم، فلش، مستطیل، بیضی و متن).
  - ذخیره‌ی نما، شامل دوربین، سکشن و Tagها، با لینک مستقیم به همان نما.
- **موبایل**:
  - چرخش با یک انگشت، جابه‌جایی و زوم با دو انگشت.
  - دابل‌تپ برای نزدیک شدن به یک نقطه.
  - **حالت راه رفتن** با جوی‌استیک، کشیدن انگشت برای نگاه کردن، دکمه‌های بالا و پایین، **ژیروسکوپ** (گوشی را بچرخانید تا اطراف را ببینید)، جاذبه و برخورد با دیوار، و دابل‌تپ برای پرش به یک نقطه.
  - روی دسکتاپ کلیدهای WASD کار می‌کنند.
- **اشتراک‌گذاری**:
  - لینک با رمز، تاریخ انقضا، واترمارک، و اجازه‌ی دانلود و کامنت.
  - ثابت کردن لینک روی یک نسخه، یا باز شدنش روی یک نمای مشخص.
  - **QR Code** و آمار بازدید.
- **پنل ادمین**:
  - کاربرها با نقش‌های admin، editor و viewer.
  - دسترسی روی پروژه یا مدل با نقش‌های viewer، commenter و editor.
  - مدیریت لینک‌ها و توکن‌های پلاگین.
  - مصرف فضا، پاک‌سازی آپلودهای ناتمام، و گزارش فعالیت.
- **آفلاین**: با دکمه‌ی «Save offline» مدل در خود اپ ذخیره می‌شود و بدون اینترنت باز می‌شود. صفحه‌ی **Offline** فهرست مدل‌های ذخیره‌شده، حجمشان، دکمه‌ی حذف تکی و حذف همه را نشان می‌دهد. اپ قابل نصب روی صفحه‌ی اصلی گوشی است (PWA).
- **دانلود**: فایل `.skp` اصلی برای SketchUp Pro و `.glb`.

### پیشنهادهای اضافه که پیاده شده‌اند
۱. **چرخه‌ی تأیید کارفرما**: Approve یا Request changes روی هر نسخه.
۲. **مقایسه‌ی نسخه‌ها** با اسلایدر کشویی.
۳. **QR Code** برای لینک‌ها.
۴. **واقعیت افزوده (AR)**: در iOS با Quick Look و در اندروید با WebXR، در اندازه‌ی واقعی یا رومیزی.
۵. **حالت ارائه**: پخش خودکار Sceneها مثل اسلایدشو.
۶. **سایه و خورشید**، و حالت‌های X-Ray و Wireframe.
۷. **لیست کامپوننت‌ها (متره)** با تعداد و ابعاد، و خروجی CSV.
۸. **واترمارک** و غیرفعال کردن دانلود برای لینک‌های عمومی.

## نصب روی هاست اشتراکی (cPanel یا DirectAdmin)

**نیازمندی‌ها:** PHP 8.1 یا بالاتر با افزونه‌های `pdo_mysql`، `zlib` و `mbstring`، و MySQL یا MariaDB. نیازی به Node، Composer یا SSH روی هاست نیست.

۱. روی کامپیوتر خودتان (یک بار) بسته را بسازید. این کار به Node 18 یا بالاتر و Python 3 نیاز دارد:
```bash
tools/package.sh
```
خروجی دو فایل است: `dist/skpshare-server.zip` و `dist/skpshare-1.0.0.rbz`.

۲. در پنل هاست یک **دیتابیس MySQL** خالی و یک کاربر برایش بسازید.

۳. فایل `skpshare-server.zip` را در `public_html` (یا یک زیرپوشه) آپلود و Extract کنید.

۴. آدرس `https://your-site/install.php` را باز کنید و اطلاعات دیتابیس و اکانت ادمین را وارد کنید. نصب‌کننده، اندازه‌ی تکه‌های آپلود را خودش با محدودیت هاست تنظیم می‌کند.

۵. **فایل `install.php` را از هاست پاک کنید.**

۶. **SSL (https)** را در پنل هاست فعال کنید. ژیروسکوپ، AR و حالت آفلاین فقط روی https کار می‌کنند.

> کد برنامه در پوشه‌ی `_app` است و با `.htaccess` از دسترس عموم بسته شده. اگر هاست اجازه می‌دهد، امن‌ترش این است که محتوای `_app` را یک سطح بالاتر از `public_html` بگذارید. `index.php` هر دو حالت را خودش تشخیص می‌دهد.

## نصب پلاگین SketchUp
۱. در سایت به **Account** بروید و پلاگین (`.rbz`) را دانلود کنید.
۲. در SketchUp: **Extensions → Extension Manager → Install Extension** و فایل `.rbz` را انتخاب کنید.
۳. در سایت از **Account → Plugin tokens** یک توکن بسازید.
۴. در SketchUp: **Extensions → SkpShare → Publish → Settings**. آدرس سایت و توکن را وارد کنید و **Test connection** را بزنید.
۵. پروژه و مدل را انتخاب کنید و **Publish** را بزنید. اگر مدل را دوباره منتشر کنید، به‌صورت **نسخه‌ی جدید** همان مدل ذخیره می‌شود.

فشرده‌ساز `gltfpack` داخل پلاگین است، برای Windows و برای Macهای Apple Silicon. روی Macهای اینتل، پلاگین مدل را بدون فشرده‌سازی هندسه آپلود می‌کند. instancing همچنان اعمال می‌شود، پس حجم باز هم کم می‌شود.

## نکات هاست اشتراکی
- محدودیت `upload_max_filesize` مشکلی ایجاد نمی‌کند، چون آپلود در تکه‌های کوچک انجام می‌شود.
- **فضای دیسک** را در Admin → Overview زیر نظر داشته باشید. نسخه‌های قدیمی را از صفحه‌ی مدل (Info → Versions) پاک کنید.
- اگر هاست درخواست‌های `PUT` و `DELETE` را مسدود کرده باشد، اپ به‌طور خودکار از `POST` استفاده می‌کند.

## ساختار پروژه
```
server/   بک‌اند PHP و MySQL (API، آپلود تکه‌ای، اشتراک، دسترسی‌ها، نصب‌کننده)
web/      فرانت‌اند: Vite، Preact و three.js (نمایشگر، ادمین، PWA)
plugin/   پلاگین Ruby برای SketchUp (exporter، فشرده‌سازی، آپلود)
tools/    ساخت .rbz و بسته‌ی سرور
```

## توسعه و تست
```bash
php server/tests/run.php
```
```bash
ruby plugin/test/exporter_test.rb
```
```bash
cd web && npm install && npm run build
```
```bash
cd server && php -S 127.0.0.1:8089 -t public dev-router.php
```
تست‌ها چیزهای زیر را پوشش می‌دهند:
- **API**: ۵۶ تست شامل احراز هویت، CSRF، آپلود تکه‌ای با ادامه و چک‌سام، دسترسی‌ها، لینک رمزدار، منقضی و لغوشده، کامنت مهمان، تأیید نسخه و حذف.
- **exporter پلاگین**: با یک شبیه‌ساز API اسکچ‌آپ اجرا می‌شود. GLB تولیدی با `gltf-validator` بررسی و با gltfpack فشرده می‌شود.
- **کل جریان در مرورگر (Playwright)**: ورود، باز کردن مدل، Sceneها، سکشن و Section Box، اندازه‌گیری، کامنت، خط، هایلایت، مارکاپ، مقایسه‌ی نسخه‌ها، تأیید، لینک اشتراک روی آیفون، حالت راه رفتن، و ذخیره و باز کردن مدل بدون اینترنت.

**محدودیت تست:** پلاگین روی SketchUp واقعی اجرا نشده، چون این محیط لینوکسی است. منطق آن با شبیه‌ساز API تست شده. لطفاً اولین Publish را روی یک مدل کوچک امتحان کنید.

## English summary
SkpShare = a PHP/MySQL web app (runs on plain shared hosting) + a SketchUp 2021+ extension.

- **Plugin**: exports an instanced GLB and compresses it with the bundled `gltfpack` (meshopt + KTX2). It also builds a small preview GLB and a manifest with scenes, tags, section planes and the component list, gzips the original `.skp`, and uploads everything in resumable chunks.
- **Viewer** (three.js):
  - Progressive loading and GPU instancing.
  - Sections: plane, box and SketchUp's own planes, with filled caps.
  - Measure with snapping, lines, highlighter, 3D comments and 2D markup.
  - Saved views, walk mode with joystick and gyroscope, swipe version compare, AR, presentation mode.
  - X-ray, wireframe and shadows.
- **Platform**:
  - Share links with password, expiry, watermark and QR code; approval workflow.
  - Admin panel for users, project/model permissions, links, tokens, storage and activity.
  - Offline library (PWA + Cache Storage).

Deploy: run `tools/package.sh`, upload `dist/skpshare-server.zip` to `public_html`, open `/install.php`, then delete `install.php`.
