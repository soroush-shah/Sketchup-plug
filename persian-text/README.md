# متن فارسی (Persian Text) برای اسکچ‌آپ

پلاگینی برای نوشتن **متن فارسی/عربی درست** (حروف چسبیده و راست‌به‌چپ) به‌صورت هندسه‌ی دوبعدی یا سه‌بعدی داخل اسکچ‌آپ، با **هر فونتی که روی ویندوز نصب است**. متن بعداً قابل ویرایش است.

## نصب
1. فایل `dist/bs_persian_text_v1.0.0.rbz` را دانلود کنید.
2. در اسکچ‌آپ: `Extensions → Extension Manager → Install Extension` و فایل ‎.rbz‎ را انتخاب کنید.
3. نوار ابزار «متن فارسی» ظاهر می‌شود (یا از منوی `Extensions → متن فارسی`).

نسخه‌های پشتیبانی‌شده: **SketchUp 2017 تا 2027** روی ویندوز.
- از ۲۰۱۹ به بعد از موتور **HarfBuzz** استفاده می‌شود (همان موتوری که کروم و اندروید با آن متن را می‌چینند).
- در ۲۰۱۷ و ۲۰۱۸، که مرورگر داخلی‌شان WebAssembly ندارد، از موتور سازگار (opentype.js) استفاده می‌شود. کیفیتش خوب است ولی فونت‌های ‎.ttc‎ و فونت‌های متغیر در آن کار نمی‌کنند.

## امکانات
- **اتصال صحیح حروف و راست‌به‌چپ واقعی**، همراه با نیم‌فاصله، «لا» و لیگاچرهای فونت (مثل «الله»).
- **متن ترکیبی** فارسی و انگلیسی و اعداد، مثل «ساختمان شماره 12 (بلوک A)».
- **انتخاب فونت از فونت‌های نصب‌شده‌ی ویندوز**، شامل فونت‌هایی که فقط برای کاربر فعلی نصب شده‌اند:
  - هر فونت در لیست با همان متن خودتان پیش‌نمایش داده می‌شود.
  - با جستجو و فیلتر «فقط فونت‌های فارسی» (فونت‌هایی که «پ» و «ی» فارسی دارند) راحت پیدا می‌شوند.
  - سبک‌ها (Regular، Bold و…) جدا قابل انتخاب‌اند.
  - برای فونت‌های متغیر (مثل Vazirmatn) اسلایدر وزن دارید.
  - دکمه‌ی «فایل فونت…» یک فونت نصب‌نشده را هم بارگذاری می‌کند.
- **پیش‌نمایش زنده** با ابعاد واقعی متن به واحد مدل.
- **ویرایش بعدی:** روی متن راست‌کلیک کنید و «ویرایش متن فارسی» را بزنید، یا از دکمه‌ی دوم نوار ابزار استفاده کنید. همه‌ی تنظیمات روی خود متن ذخیره شده است.
  - اگر متن کپی شده باشد، می‌توانید فقط همان یکی یا همه‌ی کپی‌ها را ویرایش کنید.
- **چسبیدن به سطح** مثل ابزار اصلی 3D Text: متن یک کامپوننت glue‌شونده است و با ماوس روی دیوار، کف و… قرار می‌گیرد.
- اندازه با هر واحدی وارد می‌شود (`30cm`، `1.2m`، `12"`). دو معیار ارتفاع دارید: «اندازه‌ی فونت» یا «ارتفاع واقعی کل متن».
- تراز راست، وسط یا چپ، متن چندخطی، و تنظیم فاصله‌ی سطرها، کلمات و حروف لاتین.
- **ضخیم/نازک کردن** دلخواه (برای برش لیزر، CNC و تابلوسازی خیلی به‌کار می‌آید) و **کج کردن** (ایتالیک مصنوعی).
- **متن روی قوس:** شعاع مثبت قوس رو به بالا می‌سازد و شعاع منفی قوس رو به پایین.
- **سطح پر** یا **فقط خط دور**، **اکسترود** به هر ضخامتی، **فاصله از سطح** برای جلوگیری از تداخل (z-fighting)، و نرم‌شدن خودکار لبه‌های کناری حروف اکسترودشده.
- **متریال:** از متریال‌های مدل انتخاب کنید یا یک رنگ دلخواه بدهید تا متریالش خودکار ساخته شود.
- تبدیل خودکار اعداد به فارسی و هشدار وقتی فونت بعضی حروف را ندارد.
- آخرین تنظیمات (فونت، اندازه و…) برای دفعه‌ی بعد ذخیره می‌شود.
- میان‌برها: `Ctrl+Enter` برای ساخت و `Esc` برای بستن.

## ساختار کد
```
src/
  bs_persian_text.rb            ← لودر افزونه
  bs_persian_text/
    main.rb                     ← منو، نوار ابزار، منوی راست‌کلیک
    dialog.rb                   ← پنجره‌ی HtmlDialog و ارتباط Ruby↔JS
    fonts.rb                    ← اسکن فونت‌های ویندوز (خواندن مستقیم جدول name/cmap)
    builder.rb                  ← ساخت سطح، سوراخ‌ها، اکسترود و متریال؛ ذخیره‌ی پارامترها
    ui/engine.js                ← چیدن متن (HarfBuzz/opentype.js) + BiDi + Clipper (ادغام و ضخیم‌کردن) + قوس
    ui/app.js, index.html, style.css
    ui/lib/                     ← harfbuzzjs 0.3.6 (wasm)، opentype.js 1.3.4، clipper-lib 6.4.2
```

روند کار: پنجره فایل فونت را از Ruby می‌گیرد. HarfBuzz متن را می‌چیند و منحنی‌های حروف را می‌دهد. Clipper همه را به چندضلعی‌های تمیز (بیرونی و سوراخ) تبدیل می‌کند. Ruby از این چندضلعی‌ها سطح می‌سازد و در صورت نیاز اکسترود می‌کند.

## ساخت فایل ‎.rbz‎
```
python3 build.py
```
