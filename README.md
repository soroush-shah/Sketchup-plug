# MEP Studio for SketchUp

پلاگین مدل‌سازی تاسیسات مکانیکی، اطفای حریق، آبرسانی و برق، همراه با **تشخیص تداخل (Clash Detection)**.
سازگار با SketchUp 2021 تا 2026 و آماده برای 2027 (Ruby 3.4)، روی ویندوز و مک. Ruby خالص است و فایل باینری ندارد.

## نصب
1. فایل `dist/mep_studio_v1.0.0.rbz` را دانلود کنید.
2. در SketchUp از منوی `Extensions > Extension Manager > Install Extension` فایل را انتخاب کنید.
3. منو در `Extensions > MEP Studio` قرار می‌گیرد. تولبار را از `View > Toolbars > MEP Studio` روشن کنید.

## امکانات
| بخش | ابزار |
|---|---|
| HVAC | فن کویل پارامتریک (کانالی ۲۰۰ تا ۱۴۰۰ CFM، کاستی، سقفی روکار، زمینی) با کانکتور رفت و برگشت هوا، آب سرد/گرم و درین. چپ‌دست/راست‌دست. آویز از سقف یا تراز از کف. افزودن مدل دلخواه. |
| داکت | رسم با کلیک (تراز، سایز، شعاع زانو، عایق) یا ساخت از روی خطوط انتخاب‌شده (شبکه انشعاب‌دار). مستطیلی و گرد. شروع خودکار از خروجی فن کویل با همان سایز. |
| دریچه | دیفیوزر مربعی و گرد، گریل برگشت، اسلات خطی، چیدمان شبکه‌ای در سطح سقف |
| لوله‌کشی | CHWS/CHWR/HWS/HWR/درین/آب مصرفی/فاضلاب/اسپرینکلر/فایرهوز، DN15 تا DN300، با رنگ و تگ جدا برای هر سیستم |
| اطفای حریق | جانمایی خودکار هد اسپرینکلر بر اساس کلاس خطر (NFPA 13)، همراه با لوله‌های فرعی، دراپ و لوله اصلی که با روش Pipe Schedule سایز می‌شوند |
| برق | سینی کابل، کاندوئیت، چیدمان چراغ |
| تداخل | تاسیسات با تاسیسات و تاسیسات با سازه/معماری، Hard و Soft (حریم)، گزارش با Zoom، علامت در مدل، خروجی CSV |
| متره | طول به تفکیک سیستم و سایز، مساحت ورق داکت، تعداد تجهیزات، خروجی CSV |
| ویرایش | تغییر سایز، سیستم یا عایق داکت/لوله‌های انتخاب‌شده با حفظ مسیر |

راهنمای کلیدها: منوی `MEP Studio > Help`، یا فایل [`src/mep_studio/ui/help.txt`](src/mep_studio/ui/help.txt).
گزارش تحقیق: [`docs/research.md`](docs/research.md)
