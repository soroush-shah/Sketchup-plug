MEP Studio 1.0 - راهنمای سریع

== رسم داکت / لوله / سینی کابل ==
روی نقاط کلیک کنید. تراز طبق تنظیمات از کف (اولین نقطه) حساب می‌شود.
  Enter یا دابل‌کلیک = پایان   |   Esc = لغو   |   Backspace = حذف نقطه آخر
  Tab = پنجره تنظیمات (سیستم، سایز، تراز، شعاع زانو، عایق)
  → / ← = قفل محور X / Y      ↓ = آزاد
تایپ در کادر VCB:
  1200      طول در جهت ماوس (mm)
  400x250   سایز داکت (عرض x ارتفاع)
  d300      داکت گرد با قطر 300
  dn80      سایز لوله
  r1.5      ضریب شعاع زانو (0 = زانوی گونیا)
  e3200     تغییر تراز (یک قطعه عمودی اضافه می‌شود)
  z+1500    رایزر / دراپ عمودی از نقطه آخر
اگر اولین کلیک روی خروجی فن کویل یا دریچه باشد (نقطه بنفش)، داکت با همان سایز و سیستم
از آن خروجی شروع می‌شود. کلیک آخر روی یک کانکتور، مسیر را به آن وصل و تمام می‌کند.

== ساخت از روی خطوط ==
مسیر را با ابزار Line بکشید، خطوط را انتخاب کنید و "Duct/Pipe from Selected Edges" را بزنید.
شاخه‌ها (انشعاب‌ها) هرکدام یک مسیر جدا می‌شوند.

== فن کویل ==
Tab = انتخاب مدل، سمت لوله‌کشی، تراز. کلیک روی سقف (سطح رو به پایین) = آویز از سقف
با فاصله تعیین‌شده. کلیک روی کف = تراز زیر دستگاه از کف. → / ← چرخش 90 درجه،
تایپ عدد = زاویه، L / R = سمت لوله‌کشی. مدل جدید: HVAC > Add Fan Coil Model.

== اسپرینکلر ==
سطح کف یا سقف اتاق را انتخاب کنید > Sprinkler Layout. فاصله هدها بر اساس کلاس خطر
(NFPA 13: Light 20.9 m2/4.6 m, Ordinary 12.1 m2/4.6 m, Extra 9.3 m2/3.7 m)،
لوله‌های فرعی، دراپ‌ها و لوله اصلی با روش Pipe Schedule سایز می‌شوند.
(نتیجه را حتماً با محاسبات هیدرولیکی و ضوابط ملی کنترل کنید.)

== تشخیص تداخل (Clash) ==
تاسیسات با تاسیسات و تاسیسات با سازه/معماری (هر سطح قابل مشاهده). Hard = برخورد،
Soft = فاصله کمتر از حد مجاز. اتصالات واقعی (داکت به فن کویل، انشعاب به لوله اصلی،
دراپ اسپرینکلر) نادیده گرفته می‌شوند. دکمه Zoom دوربین را به محل تداخل می‌برد،
علامت‌ها روی تگ MEP-CLASH قرار می‌گیرند. خروجی CSV برای اکسل.

== متره ==
طول داکت/لوله به تفکیک سیستم و سایز، مساحت ورق داکت، تعداد فن کویل/هد/دریچه/چراغ.

همه اندازه‌ها میلی‌متر است. هر سیستم روی تگ (لایه) خودش قرار می‌گیرد.
